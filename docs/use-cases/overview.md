# Use Cases

CrossCall's core capability — native crosschain execution without bridges — applies broadly across DeFi and Web3 infrastructure. The protocol is designed for anyone dealing with **orderflow aggregation**, **liquidity**, **multi-chain access**, or **cross-chain settlement**.

---

## Who CrossCall Is For

| Protocol Type | How CrossCall Helps |
|---|---|
| **DEX Aggregators** | Aggregate liquidity across chains without per-chain deployments |
| **Bridges** | Offer instant atomic bridging without pool infrastructure |
| **NFT Marketplaces** | Let users on any chain buy/sell on your native chain |
| **Lending Protocols** | Enable atomic position migration across chains |
| **Orderflow Aggregators** | Extend price matching to more chains with the same infra |
| **Multichain Marketplaces** | Add new chains without backend redeploys |
